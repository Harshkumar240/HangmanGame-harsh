# CodeAlpha Hangman Game

## Project Description

This is a simple text-based Hangman game developed using Python as part of the CodeAlpha Python Programming Internship.

The player has to guess a randomly selected word one letter at a time.

## Features

- 5 predefined words
- Random word selection
- Letter-by-letter guessing
- Maximum 6 incorrect guesses
- Input validation
- Command-line interface

## Technologies Used

- Python
- Random module
- Lists
- Strings
- While loops
- If-else statements
- User input

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python hangman.py
